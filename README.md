# 道の駅検索 - iPhone Web App

## できること
- iPhoneの現在地を自動取得
- 5 / 10 / 20 / 50km以内の「道の駅」を検索
- 近い順に表示
- 道の駅の公式ホームページ（登録されている場合）を直接開く
- 公式サイトが未登録の場合はGoogleで「道の駅名 + 公式」を検索
- Appleマップで場所・経路案内を開く
- iPhoneのホーム画面に追加可能

## 公開方法
このフォルダ一式をGitHub PagesなどのHTTPS対応Webホスティングにアップロードしてください。
位置情報はHTTPSで公開したページ上で利用します。

## 注意
周辺施設データはOpenStreetMap / Overpass APIを利用します。
OpenStreetMap側で「道の駅」の名称が未登録・異なる場合、一部施設が出ないことがあります。
